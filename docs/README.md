## 📌 Descripción del Proyecto
`Luckyland-Casino-Arcade` es un sistema de gestión de base de datos relacional diseñado para administrar las operaciones complejas de un casino y centro de juegos arcade. El sistema controla usuarios, membresías, transacciones de créditos/fichas, inventario de máquinas, apuestas, premios y registros de auditoría de seguridad.
